# 三体宇宙文明档案网页作品说明

## 作品概述

本作品以刘慈欣《三体》系列为选题，制作了一个以“星际文明档案”为叙事线索的响应式单页网站。页面依次呈现起点、文明信号、六个纪元、两种文明、关键人物、黑暗森林法则、名场面档案与终章，通过统一的深空视觉和可操作交互强化主题表达。

项目采用 HTML5、CSS3 与原生 JavaScript，无框架、接口、在线字体或外部图片依赖。三颗太阳、行星轨道、信号终端、水滴、二向箔等视觉均由 HTML 与 CSS 绘制。

## 页面布局

- 单页纵向叙事：通过导航锚点连接八个主题区域。
- 分区网格：首屏为两栏 Grid，纪元为标签导航与内容面板，文明使用双栏卡片，人物与档案使用三列网格。
- 明暗节奏：深色宇宙章节与暖白色档案章节交替，减轻长页面阅读疲劳。
- 响应式断点：1120px、900px、760px、520px 逐步调整列数、字号、导航与触控按钮。

## 主要标签

| 标签 / 属性 | 页面用途 |
| --- | --- |
| `header`、`nav` | 固定导航、品牌和移动端菜单 |
| `main`、`section` | 组织八个主要内容区域 |
| `article` | 文明、人物与场景卡片 |
| `h1` 至 `h3` | 页面主题、章节与卡片层级 |
| `canvas` | JavaScript 绘制动态星空 |
| `dl`、`dt`、`dd` | 首屏数据与文明统计 |
| `blockquote` | 人物台词与主题引语 |
| `button` | 信号解码、纪元切换和坐标广播 |
| `role="tablist"`、`role="tab"`、`role="tabpanel"` | 六个纪元的无障碍标签页 |
| `aria-live` | 动态播报信号与黑暗森林状态 |

## CSS 技术

- CSS 自定义属性统一管理颜色、字体、容器宽高和缓动曲线。
- Grid 与 Flexbox 完成页面栅格、卡片、导航和按钮排列。
- `clamp()` 实现字号与间距的流式缩放。
- 伪元素、渐变和阴影绘制轨道、光晕、扫描线与场景图形。
- `@keyframes` 实现太阳漂浮、脉冲、信号波纹和页面动效。
- `prefers-reduced-motion` 为减少动态偏好的用户关闭非必要动画。

## JavaScript 交互

- Canvas 2D 与 requestAnimationFrame 绘制星空，支持高分辨率屏幕和指针视差。
- IntersectionObserver 完成滚动显现与当前章节标记。
- 纪元标签支持点击、方向键、Home 与 End 键操作。
- 信号终端按顺序输出红岸基地的警告信息。
- 黑暗森林模拟器展示坐标广播、暴露度变化与光粒打击，并可重置。
- 移动端全屏导航支持打开、跳转、Escape 关闭与页面滚动锁定。

## 运行方式

直接双击 `index.html` 即可运行。也可以在项目根目录执行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

本项目为非官方课程设计作品，仅用于 Web 前端学习与交流。

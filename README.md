# 三体宇宙 · 文明档案

一个以刘慈欣《三体》系列为主题的响应式单页网站，作为 Web 前端基础课程设计作品。页面采用“星际文明档案”的叙事结构，将三体文明、人类纪元、人物与黑暗森林法则组织成连续的沉浸式浏览体验。

## 项目亮点

- 纯 HTML、CSS、JavaScript 实现，无第三方运行时与在线资源依赖。
- Canvas 星空、CSS 天体轨道、滚动显现与轻微视差共同构成视觉系统。
- 六大纪元采用可键盘操作的无障碍标签页切换。
- “黑暗森林模拟器”提供坐标广播与打击反馈的交互演示。
- 桌面端、平板端和手机端均有独立适配，移动端提供全屏导航。
- 支持 `prefers-reduced-motion`，为减少动态偏好的用户关闭非必要动画。
- 页面使用语义化结构、跳转链接、可见焦点样式和 ARIA 状态属性。

## 页面结构

1. **起点**：主视觉、三体恒星系统、核心导语与快速入口。
2. **信号**：红岸基地信号接收终端，可点击“重新解码”。
3. **纪元**：红岸、危机、威慑、广播、掩体、银河六个纪元的标签页。
4. **文明**：三体文明与人类文明的对照卡片。
5. **人物**：叶文洁、罗辑、章北海、程心、史强、云天明人物档案。
6. **法则**：黑暗森林公理与可交互的坐标暴露模拟。
7. **档案**：古筝行动、面壁计划、水滴、二向箔等名场面。
8. **终章**：主题收束与说明文档下载入口。

## 技术实现

| 区域 | 主要技术 |
| --- | --- |
| 页面骨架 | HTML5 语义化标签：`header`、`nav`、`main`、`section`、`article`、`footer` |
| 布局系统 | CSS Grid、Flexbox、`clamp()`、媒体查询 |
| 视觉主题 | CSS 自定义属性、渐变、伪元素、`backdrop-filter`、`color-mix()` |
| 天体动画 | CSS `@keyframes`、`transform`、`box-shadow` |
| 星空背景 | Canvas 2D、设备像素比适配、`requestAnimationFrame` |
| 交互 | 原生 JavaScript、事件委托、键盘导航、定时器 |
| 动效反馈 | IntersectionObserver、滚动状态、视差变量 |
| 无障碍 | 跳过导航、ARIA 标签页、`aria-live`、焦点规则、减少动态偏好 |

## 运行方式

最简单的方式是双击 `index.html` 直接打开。项目不依赖接口、构建步骤或网络资源。

也可以在项目目录启动本地静态服务器：

```powershell
python -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 浏览器兼容

建议使用最新版 Chrome、Edge、Firefox 或 Safari。CSS 的 `color-mix()`、`backdrop-filter` 等增强特性在旧浏览器中会降级，但正文内容与主要布局仍可正常阅读。

## Git 工作流

仓库使用分阶段提交记录开发进度：

1. 初始化项目与需求整理；
2. 完成页面结构与基础视觉；
3. 增加 JavaScript 交互与响应式导航；
4. 补充作品说明、运行截图与交付材料。

可在仓库根目录运行以下命令查看历史：

```powershell
git log --graph --oneline --decorate --all
```
